## ⚡ Sobre mim

- 🐍 **Python** é uma das minhas principais linguagens, com maior experiência em **Flask** para desenvolvimento de APIs e aplicações web.
- 🚀 No back-end, gosto especialmente de trabalhar com **Flask (Python)** e **Gin (Go)**, criando APIs RESTful e integrações entre sistemas.
- ☕ Também trabalho com o ecossistema **Java**, utilizando **Spring Boot, Spring Data JPA e Hibernate**.
- ⚡ Tenho conhecimentos em **FastAPI**, para construção de APIs modernas com Python.
- 📱 Desenvolvo aplicações **Android com Flutter/Dart**.
- 🖥️ Crio sistemas **desktop com Python e Tkinter**, especialmente para automação de rotinas comerciais.
- 🕷️ Trabalho com **web scraping, automação, coleta, triagem e tratamento de dados** usando **Beautiful Soup, Selenium e Pandas**.
- 🗄️ Utilizo **MySQL, MariaDB e SQLite** para persistência e consulta de dados.
- 🐧 Tenho familiaridade com **Linux, Git, Docker e Bash** no desenvolvimento e na implantação de aplicações.
- 🎯 Busco construir soluções organizadas, eficientes e fáceis de manter, sempre aprendendo novas tecnologias.
